OBS-Setup

  1. App starten — der Overlay-Server läuft automatisch auf 127.0.0.1:8090 (nur lokal).
  2. OBS: Quellen → + → Browser; URL einer Karte oben einfügen, Größe auf den Kartenwert setzen.
  3. „Shutdown source when not visible" und „Refresh browser when scene becomes active" ausschalten — die Seiten verwalten sich selbst und reconnecten.
  4. Daten erscheinen, sobald F1 26 streamt und die App eine Session anzeigt.

In-Game-HUD (ohne OBS)

Ctrl+Shift+O blendet das HUD im Spiel ein/aus — randloser Fenstermodus empfohlen. Ctrl+Shift+R zeigt das Rivale-Panel sofort.

Layout anpassen: Tray-Icon → „Overlay position mode" → Widgets (goldene Rahmen) einzeln ziehen → Esc speichert das Layout.
